# Om Bundhe | Portfolio

A modern, responsive personal portfolio built with **React, Vite, and CSS** to showcase my skills, projects, and journey as an AI & Data Science student.

## Tech Stack
- React.js
- JavaScript, HTML5, CSS3
- Vite
- Lucide React
- Git & GitHub

## Features
- Responsive design
- About Me and Skills
- Projects showcase
- Resume access
- Contact section

## Run Locally

```bash
git clone https://github.com/ombundhe/om-bundhe-portfolio.git
cd om-bundhe-portfolio
npm install
npm run dev
```

## Build

```bash
npm run build
```
